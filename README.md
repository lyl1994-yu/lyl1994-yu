# 刘玉龙

我叫刘玉龙，做餐饮连锁和冻品商贸。我把 AI 用在日常经营里，让它帮我核对报表里的数字，也帮我把老员工的经验写成新人看得懂的工作手册。

有一次，我想估算一辆车一天送多少货值。AI 先按业务员汇总了销售额。我知道其中有几单是同事代送的，还有几户是客户自提，就把这些情况补进去，让 AI 重新算了一遍。同一批订单，算销售业绩和算配送货值，用的是两套口径。

我平时用飞书做门店巡检和客户跟进，也用它记录岗位上的真实案例。整理岗位经验时，我让 AI 帮我拟问题，再请经手的同事讲讲最近做过的一单。我尤其想听他们说说，当时看到了什么，才决定下一步这么做。这些判断写进手册前，要请经手人核实。这样，新人碰到类似的事，也知道先查什么、找谁核实、怎样交接。
